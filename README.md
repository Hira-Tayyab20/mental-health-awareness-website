# 🌿 MindfulSpace – Mental Health Awareness Website

MindfulSpace is a mental health awareness and wellness website designed to provide users with helpful resources and simple self-support tools in a friendly and accessible environment.

## ✨ Features

* 🧠 Mental health awareness and information
* 😊 Mood check-ins and mood wall
* 🌬️ Breathing/wellness tools
* 📚 Mental health resources
* 📩 Contact form
* 🔐 User registration and login
* 👨‍💼 Admin dashboard for managing resources and messages

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* PHP
* MySQL

## ⚙️ Setup

1. Download or clone this repository.
2. Place the project folder inside your XAMPP `htdocs` folder.
3. Start **Apache** and **MySQL** in XAMPP.
4. Configure the database connection.
5. Open the website through `localhost`.

## ⚠️ Disclaimer

MindfulSpace is intended for informational and self-support purposes only. It is not a substitute for professional medical advice, diagnosis, or treatment.
